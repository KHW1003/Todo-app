# PRD - Todo 앱 (초안)

> 바탕 문서: docs/IDEA.md, CLAUDE.md
> 상태: 초안. "7. 정해야 할 것"이 결정되면 해당 기능 설명에 반영한다.

## 1. 목표
혼자 쓰는 간단한 할 일 목록 웹 앱을 만든다.
할 일을 적고, 끝낸 것을 표시하고, 지울 수 있으면 된다.
초보자가 화면 → API → DB 순서로 단계별로 만들어 보는 학습용 프로젝트이기도 하다.

## 2. 대상 사용자
- 앱을 혼자 쓰는 사람 1명
- 로그인 없이 바로 쓰는 사람
- PC와 휴대폰 브라우저에서 쓴다 (Q-10)

## 3. 기능 목록

| ID | 기능 | 한 줄 설명 | 버전 |
|----|------|-----------|------|
| F-01 | 할 일 추가 | 제목을 입력해 할 일을 만든다 | v0.1 |
| F-02 | 할 일 목록 보기 | 최신순으로 보여준다 | v0.1 |
| F-03 | 완료/미완료 전환 | 체크박스로 상태를 바꾼다 | v0.1 |
| F-04 | 할 일 삭제 | 목록에서 지운다 | v0.1 |
| F-05 | 데이터 유지 | 새로고침해도 할 일이 남아 있다 | v0.1 |

## 4. 기능 상세

### F-01 할 일 추가
- 입력: 제목 (글자)
- 규칙: 앞뒤 공백을 지운 뒤 1~100자
  - 글자 수는 화면에 보이는 글자 기준으로 센다 (이모지 👍 = 1자) (Q-02)
  - 제목 가운데 공백은 그대로 둔다 ("장  보기"는 그대로 저장) (Q-03)
  - 같은 제목의 할 일도 추가할 수 있다 (Q-01)
- 추가 방법: 추가 버튼 또는 엔터 키 (Q-04)
- 동작: 규칙을 지키면 새 할 일이 "미완료" 상태로 만들어진다
- 실패: 비었거나(공백만 있는 경우 포함) 100자를 넘으면 만들지 않고 입력창 아래에 안내 문구를 보여준다 (Q-05). 문구는 docs/API_SPEC.md 8장
- 검증 위치: v0.2부터는 서버가 반드시 검증하고, 화면은 안내만 한다

### F-02 할 일 목록 보기
- 정렬: 만든 시각(created_at) 기준 최신순, 새 할 일이 맨 위
- 각 항목에 보이는 것: 체크박스, 제목, 삭제 버튼
- 할 일이 하나도 없으면 "할 일이 없습니다"를 보여준다 (Q-06)

### F-03 완료/미완료 전환
- 체크박스를 누를 때마다 완료 ↔ 미완료가 바뀐다
- 완료된 할 일의 제목은 취소선 + 회색으로 보인다 (Q-07)
- 완료/미완료가 바뀌어도 목록 순서는 바뀌지 않는다 (정렬은 만든 시각 기준)

### F-04 할 일 삭제
- 삭제 버튼을 누르면 확인 없이 바로 목록에서 사라진다 (Q-08)
- 지운 할 일은 되살릴 수 없다

### F-05 데이터 유지
버전마다 "어디까지 유지되는지"가 다르다.

| 버전 | 저장 위치 | 새로고침 | 서버 재시작 |
|------|-----------|----------|-------------|
| v0.1 | 브라우저 (localStorage) | 유지 | 해당 없음 |
| v0.2 | 서버 메모리 | 유지 | 사라짐 |
| v0.3 이후 | DB (MySQL) | 유지 | 유지 |

v0.1에서 localStorage에 쌓인 데이터는 v0.2로 옮기지 않고 버린다 (Q-09).

## 5. 사용자 스토리
- F-01: 사용자로서 할 일을 적어 두고 싶다. 잊지 않기 위해서.
- F-02: 사용자로서 가장 최근에 적은 할 일을 위에서 보고 싶다.
- F-03: 사용자로서 끝낸 일에 체크하고 싶다. 무엇이 남았는지 알기 위해서.
- F-04: 사용자로서 필요 없는 할 일을 지우고 싶다.
- F-05: 사용자로서 새로고침해도 적어 둔 할 일이 사라지지 않았으면 좋겠다.

## 6. 범위 밖 (하지 않을 것)
- 로그인
- 공유
- 알림
- 마감일
- 카테고리

## 8. 성공 기준
각 기능이 끝났다고 말할 수 있는 조건. 테스트 케이스(docs/TEST_CASES.md)의 바탕이 된다.

- F-01
  - "장보기"를 입력하면 목록 맨 위에 미완료 상태로 추가된다
  - "  장보기  "를 입력하면 "장보기"로 저장된다
  - 빈 칸, 공백만, 101자 이상을 입력하면 추가되지 않고 안내 문구가 보인다
  - 정확히 1자, 100자는 추가된다
  - 👍 이모지 100개(보이는 글자 100자)는 추가된다
  - "장  보기"는 가운데 공백 그대로 저장된다
  - 이미 있는 제목을 또 추가해도 추가된다
- F-02
  - 할 일 3개를 차례로 추가하면 마지막에 추가한 것이 맨 위에 있다
  - 할 일이 없으면 빈 목록 안내가 보인다
- F-03
  - 체크박스를 누르면 완료로, 다시 누르면 미완료로 바뀐다
  - 바꾼 상태가 새로고침 뒤에도 그대로다
- F-04
  - 삭제한 할 일은 목록에서 사라지고, 새로고침해도 다시 나타나지 않는다
- F-05
  - 할 일을 추가하고 새로고침해도 목록이 그대로다
  - v0.3 이후: 서버를 재시작해도 목록이 그대로다
